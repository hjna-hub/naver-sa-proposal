# 네이버 SA 매출 성장 전략 제안서 (GFA 톤앤매너 통일 버전)

기존 네이버 GFA 제안서와 한 세트처럼 보이도록 디자인 시스템과 조작 방식을 동일하게 맞춘 10페이지 웹 제안서입니다.

## 파일 구성

- `index.html` : SA 제안서 본문
- `styles.css` : GFA 제안서와 동일한 디자인 시스템
- `script.js` : 페이지 이동 / 목차
- `linkprice-logo.png` : LinkPrice 로고
- `.nojekyll` : GitHub Pages용 설정
- `README.md` : 업로드 방법

## 기존 SA Repository에 반영하는 방법

현재 SA Repository에서 아래 파일을 새 버전으로 교체하면 됩니다.

1. `index.html`
2. 기존 `style.css`가 있다면 삭제
3. 새 `styles.css` 업로드
4. `script.js` 교체
5. `linkprice-logo.png` 업로드
6. `.nojekyll` 업로드

GitHub Pages가 이미 켜져 있다면 Commit 후 잠시 뒤 기존 SA 링크에 자동 반영됩니다.

## GFA와 통일한 요소

- NAVER × LinkPrice 상단 브랜딩
- 화이트 / 라이트 그레이 배경
- 네이버 그린 포인트
- 동일한 헤드라인 크기와 카드 라운드
- 우측 상단 `목차`, `PDF 저장`
- 하단 페이지 번호 + 진행바 + 원형 화살표
- `#page-1` 형태의 페이지 URL
- 동일한 반응형 / 인쇄 스타일
- 질문형 헤드라인과 ‘클릭보다 매출’ 중심의 문장 톤

## 숫자 관련

5페이지 광고비 비율은 구조 설명용 예시입니다.
9페이지에는 실제 광고주 Before / After 수치를 추가해 사용하는 것을 권장합니다.
