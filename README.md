# NAVER SA Revenue Growth Proposal

GitHub Pages용 10페이지 웹 제안서입니다.

## 바로 배포하는 방법

1. 이 ZIP의 **압축을 푼 파일 전체**를 GitHub Repository의 최상단(root)에 업로드합니다.
   - `index.html`
   - `style.css`
   - `script.js`
   - `.nojekyll`
2. GitHub Repository → **Settings → Pages**
3. **Build and deployment**에서 배포 소스를 Repository의 기본 브랜치(root)로 설정합니다.
4. Pages에 표시되는 공개 URL을 복사해 광고주에게 공유합니다.

> 중요: ZIP 파일 자체를 Repository에 올리는 것이 아니라, ZIP을 풀어서 `index.html`이 Repository 최상단에 있도록 업로드하세요.

## 사용법

- 화면 하단 화살표 클릭
- 키보드 `←` `→`
- 모바일 좌우 스와이프
- URL 뒤에 `#5`처럼 붙이면 해당 페이지로 바로 이동
- 브라우저 인쇄 → PDF 저장 시 10페이지 형태로 출력 가능

## 수정 포인트

### 텍스트
`index.html`에서 원하는 문구를 검색해 바로 수정할 수 있습니다.

### 컬러
`style.css` 상단의 아래 변수만 바꾸면 전체 톤을 수정할 수 있습니다.

```css
:root {
  --bg: #f5f7f8;
  --ink: #0d0f10;
  --green: #03c75a;
}
```

### 성과 사례
9페이지의 숫자는 **샘플**입니다. 실제 광고주 데이터로 반드시 교체하세요.

### 폰트
현재 Google Fonts의 `Noto Sans KR`, `Inter`를 사용합니다.
외부 폰트 로딩이 제한되는 환경에서는 시스템 기본 sans-serif로 대체됩니다.

## 구성

01. 네이버 SA, 이제 ‘노출’보다 ‘매출’입니다  
02. 매출은 어디서 만들어지는가  
03. 우리 고객은 무엇을 검색하고 구매하는가  
04. 매출을 만드는 키워드 전략  
05. 광고비가 새는 구간을 찾아라  
06. ROAS 500%인데 왜 돈을 못 벌까요?  
07. 광고가 아닌 ‘상품’까지 최적화해야 합니다  
08. SA만 잘하면 되는 시대인가?  
09. 실제 매출 개선 사례  
10. 우리 브랜드의 다음 성장 액션  

## 실무 권장사항

공통 제안서에서는 9페이지 사례를 업종별 대표 사례로 교체하고,
10페이지 마지막 문장을 광고주/브랜드명에 맞춰 개인화하면 제안력이 더 좋아집니다.
